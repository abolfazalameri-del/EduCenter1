# مدیریت مرکز آموزشی — نرم‌افزار آفلاین ویندوز (برندینگ داینامیک)

> **چاپ / خروجی:** هر دکمه‌ی «چاپ» پنجره‌ای با گزینه‌های Word، Excel، PDF، تصویر، CSV و صفحه وب باز می‌کند (گزینه‌ی مناسب سند پیشنهاد می‌شود). از «تنظیمات ← ظاهر و خروجی من» می‌توانید خروجی دلخواه یا «هر بار بپرس» را تعیین کنید.

> **پالت رنگی:** دکمه‌ی 🎨 در نوار بالا؛ هر کاربر پالت (یا رنگ دلخواه) خودش را انتخاب می‌کند.

> **چند شعبه:** از منوی «شعبه‌ها» شعبه بسازید؛ انتخاب‌گر شعبه در نوار بالا ظاهر می‌شود. کاربر «مدیر شعبه» (یا هر کاربر وابسته به شعبه) فقط اطلاعات شعبه‌ی خودش را می‌بیند. داده‌ی قدیمی خودکار به «شعبه مرکزی» منتقل می‌شود.

> نام، لوگو، آیکن، رنگ و مشخصات مرکز از «تنظیمات ← اطلاعات مرکز آموزشی» تغییر می‌کند و در صفحه ورود، عنوان پنجره، آیکن برنامه، منو، گزارش‌ها، PDF و رسیدها نمایش داده می‌شود.

برنامه‌ی دسکتاپ Electron برای مدیریت کامل یک مرکز آموزشی: شاگردان، والدین، استادان و کارمندان، صنوف و مضامین، تقسیم اوقات، حاضری (شاگردان و کارکنان)،
امتحانات و نمرات و کارنامه، فیس و رسید، حسابداری، معاشات، انضباط، دارایی و گدام، اطلاعیه‌ها، اسناد، سال تعلیمی، کاربران و صلاحیت‌ها، گزارش فعالیت‌ها،
پشتیبان‌گیری/بازیابی. کاملاً آفلاین؛ داده‌ها روی همین کامپیوتر (پوشه‌ی userData برنامه) ذخیره می‌شود.

## اولین اجرا
رمز پیش‌فرض وجود ندارد. در اولین اجرا حساب مدیر سیستم را بسازید (رمز ≥۸ کاراکتر، شامل حرف و عدد). **کد بازیابی فقط یک‌بار نمایش داده می‌شود؛ آن را روی کاغذ بنویسید.**
کاربران جدید یا رمزهای بازنشانی‌شده در اولین ورود باید رمز را تغییر دهند.

## نقش‌ها
مدیر سیستم، مدیر مرکز آموزشی، معاون، سرمعلم، استاد، مدیر مالی/حسابدار، پذیرش، کارمند اداری. صلاحیت هر نقش در «کاربران و صلاحیت‌ها ← صلاحیت نقش‌ها» قابل تنظیم است.
کنترل دسترسی در پردازه‌ی اصلی (`lib/service.js` + `lib/authz.js`) برای هر IPC انجام می‌شود، نه فقط با پنهان‌کردن منو.

## پشتیبان‌گیری
دستی، خودکار (بعد از تغییر)، زمان‌بندی دوره‌ای و هنگام خروج (در صورت تغییر). پوشه قابل انتخاب است. Restore ابتدا نسخه‌ی ایمن می‌گیرد، نسخه را در پوشه‌ی موقت می‌سازد و اعتبارسنجی می‌کند،
سپس با rename اتمیک جایگزین می‌کند و در صورت هر خطا داده‌ی فعلی را حفظ می‌کند.

## توسعه و تست
```
npm install
npm start                 # اجرای برنامه (Electron)
npm run test:unit         # store + سرویس/امنیت/Restore (Node)
npx playwright install chromium && npm test   # + E2E واقعی با Chromium و PDFهای واقعی (نیازمند poppler-utils و python3-pil)
```

## ساخت Installer ویندوز (GitHub Actions)
1. پروژه را در یک مخزن GitHub بگذارید (شاخه‌ی main) و push کنید — یا در تب Actions گزینه‌ی **Run workflow** را بزنید.
2. Workflow «Build Windows Installer»: ابتدا job `test` (تست‌های unit + E2E واقعی) روی Ubuntu؛ سپس job `windows-build`:
   self-test در Electron واقعی (IPC، احراز هویت، Restore، printToPDF، ایزوله‌بودن رندرر) ← `npm run dist -- --publish never` (بدون GH_TOKEN) ←
   بررسی وجود و PE بودن `EduCenterManager-Setup-<version>.exe` ← نصب بی‌صدا، اجرای self-test از نسخه‌ی نصب‌شده و حذف ← آپلود artifact.
3. اگر هر مرحله (از جمله ساخت Installer) شکست بخورد، workflow قرمز می‌شود. Installer را از Artifacts با نام `SchoolManagement-Windows-Installer` بگیرید.

مسیر محلی خروجی: `dist/EduCenterManager-Setup-<version>.exe`.

## وضعیت راستی‌آزمایی
فهرست دقیق PASS/FIXED/NOT VERIFIED در `PROJECT_PROGRESS.md` و `TEST_REPORT.md`. Installer در محیط ساخت این نسخه ساخته **نشد** (بدون Windows/اینترنت)؛ ساخت و تأیید آن با GitHub Actions انجام می‌شود.
